# Portfólio React

## Sobre o Projeto

Este projeto foi desenvolvido como atividade prática do curso de React.

O objetivo é criar um portfólio online para apresentar habilidades, projetos desenvolvidos durante os estudos e formas de contato.

O site possui um visual inspirado em cafeterias e foi desenvolvido com foco em organização, componentização e responsividade.

## Tecnologias Utilizadas

* React
* JavaScript
* HTML5
* CSS Modules
* Vite

## Como Executar o Projeto

Clone o repositório:

```bash
git clone LINK_DO_REPOSITORIO
```

Entre na pasta do projeto:

```bash
cd portfolio
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

Acesse no navegador:

```bash
http://localhost:5173
```

## Projetos Apresentados

### Coffee Talk

Projeto de cafeteria desenvolvido utilizando React, com foco em interface moderna e navegação entre seções.

### TaskLab

Aplicação para gerenciamento de tarefas, permitindo organizar atividades de forma simples e prática.

### Restaurante Micro Frontend

Projeto desenvolvido utilizando conceitos de Micro Frontends e Module Federation para integração de aplicações independentes.
